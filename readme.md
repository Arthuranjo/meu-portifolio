## 👨‍💻 Sobre o Projeto

Este projeto consiste no desenvolvimento do meu **portfólio profissional**, criado para apresentar de forma moderna e interativa minha trajetória acadêmica, conhecimentos técnicos, projetos e experiências com desenvolvimento de software.

O objetivo foi construir uma página única, responsiva e visualmente agradável, utilizando tecnologias modernas de desenvolvimento Front-end e bibliotecas de animação.

Além de apresentar meus projetos, o portfólio também funciona como uma demonstração prática das tecnologias que venho estudando e utilizando durante minha formação.

---

## 🎯 Objetivos

O portfólio foi desenvolvido com os seguintes objetivos:

- 🧑‍💻 Apresentar meu perfil profissional
- 📚 Mostrar minha formação acadêmica
- 🚀 Destacar projetos desenvolvidos
- 💻 Apresentar minhas principais tecnologias
- 🏆 Exibir certificações e cursos
- 📈 Demonstrar minha evolução como desenvolvedor
- 📬 Disponibilizar formas de contato
- 🎨 Criar uma interface moderna e responsiva
- ⚡ Aplicar animações e interações na interface

# 🚀 Executando Localmente

Como o projeto utiliza apenas tecnologias Front-end, não é necessário instalar dependências complexas.

Clone o repositório:

```bash
git clone https://github.com/Arthuranjo/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

Depois basta abrir o arquivo:

```text
index.html
```

ou utilizar uma extensão como **Live Server** no VS Code para executar o projeto localmente.
